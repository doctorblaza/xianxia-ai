## 世界观一句话

修炼体系「码修」——以手写代码为修炼法门。陈氏码阁是码修第一世家，
新兴势力「天算七宗」靠吞噬灵脉（算力）炼「大模型金丹」，为夺陈氏祖传
「源代码灵脉」灭了码阁满门。少主陈砚与小师妹逃入断网崖，无师自通，
练成之后逐一向七位宗主复仇。

## 反转

灭门夜里应外合，事后生死未卜。终局宗主撕下伪装，"三长老"再现。
