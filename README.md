# 码修 · xianxia-ai

**在线游玩：https://doctorblaza.github.io/xianxia-ai/**

水墨仙侠风网页 AVG + 算法战斗游戏。画风参考《仙剑奇侠传》水墨彩绘。

修炼体系「码修」——以手写代码为修炼法门。陈氏码阁是码修第一世家，
新兴势力「天算七宗」靠吞噬灵脉（算力）炼「大模型金丹」，为夺陈氏祖传

## 玩法

- 单线剧情，无任何分支，共 9 章、238 句台词。
- 对话推进剧情，说话人的透明立绘显示在 UI 左侧。
- 全程 10 处「算法战」：LeetCode 风格 Python 算法题，
  按剧本位置固定出题——每处战斗有 2~3 道同主题、同难度的备选
  （BFS/DFS、回溯、动态规划、双指针、贪心、二分查找、滑动窗口、栈、链表、最短路），
  按该战斗已通关次数确定性轮换，不随机、不跨难度，
  难度随剧情推进递增（★ 入门 → ★★ 进阶 → ★★★ 精深），
  全部测试用例通过才能继续剧情。
- Python 在浏览器内通过 Pyodide（CDN）真实执行，无需后端。
- 自动存档 / 手动存档 / 读档；BGM 开关。

## 技术栈

- 纯静态页面：HTML + CSS + 原生 JS，无构建步骤，可直接用 GitHub Pages 托管。
- `js/py.js`：Pyodide 加载与测试判定（`PyRunner.runTests`）。
- `js/problems.js`：45 道算法题题库（`theme` 字段标识算法主题；`BATTLE_PROBLEMS` 映射剧本战斗名 → 2~3 道同主题同难度的备选题）。
- `js/story.js`：完整剧本，由 `剧本-码修.md` 自动解析生成（解析器已随项目归档）。
- `js/engine.js`：AVG 引擎（对话 / 立绘 / 背景 / BGM / 存档）。
- 本地运行：`cd xianxia-ai-game && python3 -m http.server 8765`，打开 `http://localhost:8765/`。
